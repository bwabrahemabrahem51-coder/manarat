# منارة الحدباء للاستثمار العقاري

تطبيق ويب (ملف واحد `index.html`) لإدارة الأحياء والعقارات وطلبات الزبائن، مع مزامنة سحابية عبر Supabase.

## الملفات
- `index.html`: التطبيق كامل
- `sw.js`: يخلي الواجهة تشتغل بدون إنترنت (لازم يكون بنفس مجلد index.html)
- `supabase_schema.sql`: جدول `aqarati_items` وسياسات الحماية (RLS)

## تجهيز Supabase
1. افتح مشروعك في Supabase ثم **SQL Editor ← New query**.
2. الصق محتوى `supabase_schema.sql` واضغط **Run**.
3. **Authentication ← URL Configuration**: ضع رابط الموقع في Site URL وأضفه في Redirect URLs (حتى يشتغل رابط تأكيد الإيميل واستعادة كلمة المرور).
4. المفتاح داخل `index.html` لازم يكون **anon / publishable** فقط. لا تضع `service_role` أبداً.

## ملاحظة أمان
دخول المكتب يطلب كلمة سر حساب المكتب عند الدخول، وما مخزنة بالكود. إيميل المكتب ظاهر بالملف، فخلّي الريبو **Private** إذا تريده يبقى مخفي.
